# DO LAR - Bolos Caseiros

Site por Pedro Oliveira com catálogo de sabores, busca, filtros, ampliação dos produtos e seleção de encomendas pelo WhatsApp.

Para atualizar sabores e preços, editar app.js. Os arquivos de imagem e o cardápio PDF ficam na raiz do repositório.
